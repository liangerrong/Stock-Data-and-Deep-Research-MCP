## 1. 执行摘要

**结论：战略级买入机会，但需承受短期波动**

阿里巴巴正经历从"电商巨头"到"AI基础设施公司"的深刻转型。FY2025总收入RMB 9,963亿(+6%)，GAAP净利RMB 1,260亿(+77%)，但自由现金流因AI基建CapEx激增而暴跌53%至739亿。核心电商淘天集团贡献43.6%的EBITA利润率，但市场份额持续被拼多多/抖音侵蚀。新增长引擎方面，云智能EBITA增长72%，AIDC国际在FY2026Q2首次盈利，外卖因京东入局再陷补贴大战。[T1: FY2025 20-F]

管理层宣布3年≥RMB 3,800亿AI基建投入，Qwen3大模型下载量超6亿，这是一场"all-in AI"的豪赌。当前PE 24x远低于全球科技同行44x均值，42位分析师共识"强力买入"目标价$198(+22%)。[T2]

**核心投资逻辑**：若AI+云成功兑现（云收入持续30%+增长 + AIDC持续盈利），当前估值存在显著上行空间；但若AI投资ROI不及预期，FCF将长期承压，估值折价可能合理。

### 3.3 核心业务详解

#### 淘天集团 — 现金牛，但增速放缓

- **CMR(客户管理)收入**：3,224亿(+6%)，核心变现引擎
  - Take rate提升：2024年9月启动基础软件服务费(0.6%)
  - GMV ~8万亿 → Take rate ~4.0% [T3: 推算]
- **直营收入**：1,028亿(-7%)，天猫超市/盒马规模化收缩
- **竞争压力**：份额从51.3%(2021)→37.3%(2024)，增量被PDD/抖音分走
- **组织变革**：FY2026将整合饿了么+飞猪为"中国电商事业群" [T1]

#### AIDC国际 — 增长最快，亏损转盈

- **收入**：1,323亿(+29%)，最高增速板块
- **FY2026Q2**：首次录得EBITA盈利1.62亿，里程碑事件
- **速卖通**：Choice托管模式驱动增长，菜鸟5日达提升体验
- **Lazada**：东南亚市场大幅减亏
- **Trendyol**：土耳其本地业务盈利
- **风险**：跨境电商监管(美国de minimis取消/欧盟税改)

#### 云智能 — AI驱动，利润新引擎

- **收入**：1,180亿(+11%) → FY26Q2加速至+34%
- **EBITA**：106亿(+72%)，利润率9.0%→持续提升
- **AI相关收入**：连续7季度三位数增长
- **市场地位**：IaaS中国第一(26.1%份额)，但华为云/运营商云追赶
- **Qwen3**：>6亿下载/17万衍生模型，开源策略建立生态壁垒

## 5. 竞争格局

### 5.1 中国电商 — "五军之战"

```
份额变迁 (2021 → 2024)：          GMV规模（万亿RMB）
淘天：51.3% → 37.3% ▼▼            ~8.0
拼多多：份额快速上升 ▲▲            ~5.2
京东：稳步增长 ▲                    ~4.0-4.4
抖音：爆发式增长 ▲▲▲              ~3.4-3.5
快手：增长中 ▲                      ~1.3
```

**关键趋势**：
1. 淘天在绝对GMV仍保持第一，但份额从51%→37%，增量被分流
2. 拼多多以极致性价比+社交裂变成为最大威胁
3. 抖音/快手"兴趣电商"改变用户购物路径，从搜索→推荐

### 5.2 竞对财务PK [T2: 2024CY]

| 公司         | 收入(亿) | 增速  | 净利(亿) | 净利率 | PE   |
| ------------ | -------- | ----- | -------- | ------ | ---- |
| **阿里巴巴** | 9,963    | +6%   | 1,260    | 12.6%  | 24x  |
| 拼多多       | 3,938    | +59%  | 1,124    | 28.5%  | ~13x |
| 京东         | 11,588   | +6.8% | 414      | 3.6%   | ~10x |
| 美团         | 3,376    | +22%  | 358      | 10.6%  | ~30x |

**洞察**：拼多多以59%增速+28.5%净利率成为最赚钱的中国电商。阿里收入规模仍为最大，但利润增长停滞。

### 5.3 云计算 — 阿里云#1但追兵凶猛

- **阿里云**：IaaS 26.1%份额(第一)，AI IaaS 23%
- **华为云**：强势追赶，政企市场优势
- **运营商云**：中国电信/中国移动凭借政策支持快速上位
- **腾讯云**：稳健但增速落后
- Top 5合计70.1%市场

**AI时代变量**：Qwen3开源生态 + 3年3,800亿投入 → 可能拉大差距

### 5.4 跨境电商 — 群雄逐鹿

| 平台           | 2024 GMV | 核心优势        | 最大风险 |
| -------------- | -------- | --------------- | -------- |
| **AliExpress** | AIDC+29% | 品牌化+菜鸟物流 | 合规成本 |
| Temu           | $708亿   | 极致低价        | 监管封锁 |
| TikTok Shop    | ~$1000亿 | 内容电商        | 美国禁令 |
| SHEIN          | +30%     | 柔性供应链      | ESG争议  |

### 5.5 外卖 — 补贴大战再起

2025年竞争格局巨变：
- **2024**：美团65% / 饿了么33%（双寡头）
- **2025Q3**：美团50% / 饿了么+淘闪42% / 京东8%（三国杀）
- 京东新业务前3季度亏损157亿
- 阿里外卖相关利润同比-85%
- 饿了么整合淘宝闪购后份额回升

**对阿里影响**：本地生活将从"即将盈利"回退到"战略性亏损"，侵蚀集团利润

## 6. AI+云战略深潜

### 6.1 战略定位："AI时代的操作系统"

```
                    ┌─────────────────┐
                    │  应用层 (Apps)   │  淘天AI导购/AIDC智能营销/钉钉AI
                    ├─────────────────┤
                    │  模型层 (Models) │  Qwen3系列 (开源生态)
                    ├─────────────────┤
                    │  平台层 (PaaS)   │  百炼(Model Studio)/PAI
                    ├─────────────────┤
                    │  基础设施 (IaaS) │  数据中心/GPU集群/磐久
                    └─────────────────┘
                    3年投入 ≥ RMB 3,800亿
```

### 6.2 Qwen3模型生态

- **Qwen3-Max**：>1万亿参数，对标GPT-4
- **Qwen3-VL**：多模态视觉语言模型
- **Qwen3-Coder**：专业编程模型
- **Qwen-Image/TTS**：图像生成/语音合成
- **生态数据**：>6亿下载，>17万衍生模型，>100万百炼平台用户
- **国际认可**：新加坡选用Qwen开发区域语言模型

### 6.3 投资力度与竞争对比

| 公司         | AI CapEx计划          | 时间段       |
| ------------ | --------------------- | ------------ |
| **阿里巴巴** | ≥RMB 3,800亿(~$530亿) | FY26-28(3年) |
| 微软         | $800亿                | FY2025单年   |
| Meta         | $600-650亿            | 2025单年     |
| 字节跳动     | 传闻$200亿+           | 2025单年     |

**评估**：阿里投入量级与全球巨头可比，但在GPU获取上可能受中美限制影响。

### 6.4 风险与回报测算 [T3: 推算]

**乐观情景**：云收入FY28达2,500亿(CAGR 28%)，EBITA率15% → EBITA 375亿
**基准情景**：云收入FY28达2,000亿(CAGR 19%)，EBITA率12% → EBITA 240亿
**悲观情景**：云收入FY28达1,500亿(CAGR 8%)，EBITA率8% → EBITA 120亿

AI投入3年3,800亿的隐含年均折旧增加~200亿（10年折旧假设），直接侵蚀利润。
